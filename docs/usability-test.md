# Usability test readout

## Exercise
Eight peer participants were asked to add a sample transaction using the dashboard prototype.

| Measure | Before iteration | After iteration |
|---|---:|---:|
| Add-transaction task time | 41 seconds | 23 seconds |
| Participants | 8 | 8 |

## Changes made
- Moved the primary action into the page heading.
- Grouped related form fields and clarified labels.
- Added inline validation and a clear save confirmation.
- Made the transaction list searchable and filterable.

## Notes
This is a small formative usability exercise, not a statistically representative study. Keep participant-level timing notes in the accompanying spreadsheet if collecting a new test run.
