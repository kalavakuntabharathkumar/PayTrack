# Accessibility audit checklist

Use this checklist when repeating the audit with axe DevTools and NVDA.

- [ ] Confirm page landmarks and heading order.
- [ ] Verify every form control has a programmatic label.
- [ ] Navigate links, filters, form and export using only the keyboard.
- [ ] Confirm focus is visible and never obscured.
- [ ] Confirm add-transaction errors are announced.
- [ ] Confirm updated transaction counts and export status are announced.
- [ ] Check text and control contrast with axe DevTools.
- [ ] Test the page with NVDA in browse and focus modes.

The reported project exercise recorded 31 fixes and a Lighthouse accessibility score moving from 64 to 98. Scores vary by browser, viewport, Lighthouse version and test conditions; rerun Lighthouse to validate the result.
